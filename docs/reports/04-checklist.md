# قايمة التأكد إن كل حاجة شغّالة (بعد النشر)

اتبع الخطوات بالترتيب. كل خطوة فيها "المفروض يحصل إيه".

## 0) فحص تلقائي

`node scripts/smoke-check.mjs https://دومينك.vercel.app` — كل السطور ✓.

## 1) عميل جديد

1. `/portal-login.html` ← تبويب "عميل جديد" ← املا البيانات برقم موبايل **ماتسجّلش قبل كده**.
   المفروض: يظهر رقم متابعة.
2. نفس الرقم تاني. المفروض: رسالة "الرقم ده مسجّل عندنا قبل كده" من غير رقم.
3. إدارة ← طلبات الانضمام: الطلب يظهر. اقبله.
   المفروض: يظهر رابط تفعيل وزرار واتساب (والإيميل لو الإعدادات متظبطة).
4. افتح رابط التفعيل ← اختار كلمة سر ← احفظ الـ 8 أكواد ← ادخل.

## 2) عميل قديم (له بيانات عندنا بس مفيش حساب بوابة)

1. تبويب "عميل قديم" ← اسم الشركة + موبايل **مالوش حساب بوابة**.
   المفروض: رسالة "وصل طلبك".
2. إدارة ← طلبات التفعيل: الطلب يظهر.
3. لو الموبايل **ليه حساب بوابة** أصلًا: مفيش طلب بيظهر (ده طبيعي) والرسالة نفسها بالظبط. الحل: "نسيت كلمة السر".

## 3) نسيت كلمة السر

`/portal-recover.html`: لازم تظهر 4 طرق في القايمة. جرّب "عندي كود من الدعم" بعد ما الإدارة تدّيك كود 8 أرقام.

## 4) الواجهة الجديدة

`/v2/portal/login` ← ادخل ← المنتجات ← أضف للسلة ← ابعت طلب ← الطلبات ← الفريق (لو رئيس).

## 5) التحويل للواجهة الجديدة

فعّل `ui.v2.portal` وافتح `/portal-login.html`: المفروض يحوّلك. `?legacy=1` يرجّعك للقديمة.
