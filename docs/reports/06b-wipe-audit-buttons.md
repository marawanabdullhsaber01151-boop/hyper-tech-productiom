# دفعة: مسح العملاء + سجل التدقيق بالعربي + إصلاح الأزرار

## 1) سكريبت مسح العملاء — scripts/wipe-customers.mjs
- `npm run wipe:customers -- --dry-run` بيعرض اللي هيتمسح من غير ما يمسح.
- `npm run wipe:customers` بيطلب تكتب «امسح العملاء» وبعدين يمسح نهائي.
- بيمسح العملاء/المستخدمين/الطلبات/الفواتير/الطلبات الإنتاجية وكل الجداول المرتبطة، ويرجّع المخزون، ويعيد بناء سلسلة السجل ويصفّر العدّادات.
- المحمي (المستخدمين الداخليين، الإعدادات، المنتجات...) مابيتلمسش.
- أي خطأ = rollback كامل.

## 2) سجل التدقيق بالعربي
- `src/lib/auditNarrative.ts` بيحوّل كل صف لجملة عادية + الوقت للدقيقة.
- `GET /governance/audit` بيرجّع `sentence` و`whenText`.
- صفحة governance بقت: إيه اللي حصل / مين / النتيجة / امتى.

## 3) الأزرار
- السبب: شاشات الأدمن lazy ونفس المكان بيتعاد استخدامه، فالشاشة القديمة كانت بتفضل لحد الريفرش.
- الإصلاح في `Lazy` (web/src/admin/routes.tsx).
