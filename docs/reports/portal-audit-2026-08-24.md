# فحص وإصلاح بوابة العملاء — 2026-08-24

## المشاكل المؤكدة التي تم إصلاحها

1. طبقة الـ API الموحدة كانت تعيد الرد الناجح داخل `data`، بينما
   `portal-auth.js` و`portal.js` كانا يقرآن الرد الخام. هذا كان يجعل التوكن
   لا يُحفظ في مكانه الصحيح، ويجعل كتالوج المنتجات يتعامل مع object بدل array.
2. صفحة «طلباتي» كانت تفك `data` مرة إضافية بعد إصلاح العميل، فتم توحيد التعامل
   مع الـ envelope.
3. `minimumOrderQuantity` كان يصل من التسجيل والواجهة، لكنه لا يُحفظ في
   `portal_customers` عند إنشاء الحساب.
4. بيانات الحساب كانت تعرض الحد الأدنى كقيمة غير موجودة لأن `/portal/me` لم
   يرجعه.
5. تعديل بيانات الحساب لم يكن يحفظ الحد الأدنى في قاعدة البيانات.
6. التحقق من كمية الطلب كان يستخدم إعدادًا عامًا فقط ويتجاهل الحد الأدنى
   الخاص بالعميل؛ أصبح التحقق يستخدم الأكبر بين الإعداد العام وإعداد العميل.
7. JSON تالف داخل `sessionStorage` كان يوقف JavaScript بالكامل؛ أصبح يتم
   تنظيف الجلسة التالفة والعودة لتسجيل الدخول.
