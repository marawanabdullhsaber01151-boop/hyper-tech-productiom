# الخطة 08 — محادثات العملاء

## الباك إند
- هجرة `0076` (إضافة فقط): عمود `member_id` في `chat_conversations`. فاضي = محادثة الشركة المشتركة. الفهرس الفريد بقى جزئي (واحدة مشتركة + واحدة لكل موظف).
- `chat.mode` (إعداد الشركة) بقى بيتنفّذ فعلًا:
  - `shared`: كل الموظفين على محادثة الشركة.
  - `per_member`: كل موظف محادثته، ومحدش بيشوف التاني.
  - `per_member_monitored`: زي اللي فوق + اللي معاه `chat.view_company` يشوف محادثات الفريق (قراءة بس).
- `chat.use` بقت مطلوبة لكل مسارات `/portal/chat/*` لجلسات الموظفين.
- الصور محمية: الموظف مايفتحش صور محادثة زميله، والرئيس بس في وضع المراقبة.
- مسارات جديدة: `GET /portal/chat/team` و`GET /portal/chat/team/:id`.
- اسم المرسل = اسم الموظف، وبيتخزن `sender_member_id`.
- عند الموظفين: عنوان المحادثة بيظهر اسم الموظف تحت اسم الشركة.

## الواجهة
- شاشة العميل `/v2/portal/chat`: رسائل بالقراءة والتسليم، صور (بتتصغّر قبل الرفع)، موضوع الرسالة، إشارة لطلب/منتج (`?context=product:12`)، تنبيه خارج مواعيد الشغل + واتساب، تقييم بعد القفل، شارة رسايل جديدة في القايمة، وتبويب «محادثات الفريق» للرئيس.
- شاشة الموظفين `/v2/admin/portal-chat`: قايمة بفلاتر وبحث، محادثة مباشرة (تحديث كل 4 ثواني)، ردود جاهزة، ملاحظات داخلية، استلام، تحويل، قفل/فتح، إخفاء رسالة بسبب، ومراجعة بالقراءة بس للمراقب.
- (خطوة 4b) التقارير و«من يرد؟» وإدارة الردود الجاهزة والإعدادات وإشعارات المتصفح بقت تبويبات في نفس الصفحة، والصفحة القديمة اتمسحت (`/chat-staff.html` بيحوّل تلقائيًا، وبيحافظ على رقم المحادثة من الإشعارات القديمة).

## الاختبارات
root 429، web 84، e2e 4 جديد (الأوضاع التلاتة، العزل، المراقبة) + باقي البوابة 67، كلها نجحت.

## ملاحظات
- المحادثة المشتركة القديمة بتفضل زي ما هي. لو غيّرت الوضع لـ«لكل موظف» الموظفين هيبدأوا محادثات جديدة.
- إشعارات Web Push بقت في الصفحة الجديدة (زر أعلى الصفحة).
