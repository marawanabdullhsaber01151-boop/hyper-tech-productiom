# Step 4b — توحيد شات الإدارة (واجهة واحدة)

## القرار
شاشة `/v2/admin/portal-chat` بقت **الواجهة الوحيدة** لمحادثات العملاء من ناحية الموظفين. الصفحة القديمة (`chat-staff.html` + `JS/chat-staff.js`) و`admin-v2-redirect.js` اتمسحوا بعد نقل كل الميزات.

## جرد الفروقات (قديم ↔ جديد) — بعد قراءة الكود
| الميزة في الصفحة القديمة | الحالة |
|---|---|
| صندوق وارد/فلاتر/بحث/محادثة/استلام/تحويل/قفل/إخفاء/ملاحظة داخلية/صور | موجودة في الجديد من قبل |
| **التقارير** (زمن الرد، التقييمات، أداء الموظفين) | **اتنقلت**: تبويب «التقارير» (مدير ومراقب) بكروت أرقام وتوزيع تقييمات وجدول موظفين |
| **من يرد؟** (صلاحية كل موظف في الشات) | **اتنقلت**: تبويب «مين يرد؟» بحث + اختيار الدور؛ صلاحيتك أنت مقفولة (السيرفر بيمنعها برضه) |
| **الردود الجاهزة (إدارة)** | **اتنقلت وتحسّنت**: إضافة + **تعديل** (جديد) + مسح بتأكيد |
| **إعدادات الشات** (أيام وساعات الشغل، إجازات، مهلة التأخير، الرد التلقائي، واتساب) | **اتنقلت**: تبويب «الإعدادات» مع تحقق قبل الحفظ بنفس قواعد السيرفر وتنضيف رقم واتساب (أرقام عربي/مسافات/+) |
| **إشعارات المتصفح (Web Push)** | **اتنقلت**: زر أعلى الصفحة، مش بيظهر لو المتصفح مش بيدعم أو السيرفر من غير VAPID |
| «آخر ظهور» للعميل + تعليق التقييم | اتضافوا في رأس المحادثة |
| لافتات (مراقبة / مقفولة / متأخرة) | اتضافت فوق المحادثة |
| تأكيد قبل قفل المحادثة (بيبعت طلب تقييم للعميل) | اتضاف |
| موضوع الرسالة (سعر/طلب/…) | بيظهر على الرسالة (للموظف والعميل) |
| عدّاد غير المقروء في عنوان التبويب + شارة على «المحادثات» | اتنقل |
| اختصار `/` في خانة الكتابة | اتشال: قايمة «رد جاهز» فوق الخانة بتعمل نفس الشغل وأنسب للموبايل |

## الصلاحيات
الأقسام بتظهر حسب `mode` اللي السيرفر بيرجّعه من `/chat/summary`: **مدير** = كل الأقسام، **مراقب** = المحادثات + التقارير، **بيرد** = المحادثات بس، **بدون وصول** = رسالة «مفيش عندك صلاحية». السيرفر هو اللي بيفرض (`managerOnly`/`staffOnly`)، والواجهة بتخفي بس.

## اللي اتغيّر خارج الشاشة
- روابط إشعارات الدفع بقت `/v2/admin/portal-chat/<id>`، و`GET /chat-staff.html[?c=<id>]` بيحوّل للصفحة الجديدة (للإشعارات والمفضلات القديمة؛ الرقم بيتحقق منه فمفيش open-redirect).
- قايمة الأقسام (`departments.ts`) بتفتح الصفحة الجديدة بنفس الأدوار. في تبويب «الشات» لكل شركة، الزر بيفتح الصندوق مفلتر باسم الشركة.
- علم `ui.v2.chat-staff` اتشال من إعدادات البوابة (فاضل علم «بوابة العميل»).

## التحقق
- `src/legacyRedirects.test.ts` (التحويل ومنع open-redirect).
- `web/src/admin/chatAdmin.test.tsx`: دوال التنسيق والتحقق، التقارير، «من يرد؟» (صلاحيتك مقفولة، الافتراضي = null)، الردود الجاهزة (تعطيل بدل مسح)، الإعدادات (رفض بدون أيام شغل، تنضيف واتساب)، وظهور الأقسام حسب الصلاحية.
- مش متاح عندي تشغيل vitest/vite (مفيش مكتبات)، فاعتمدت على فحص صيغة وأنواع جزئي؛ الفحص الكامل في `check:all` عندك.
