# الخطوة 17: مركز قيادة التشغيل (م1)

## الخطة الكاملة (م1–م4)

- **م1 (متسلّمة):** مركز القيادة، مساحة عمل الحالة، الاستلام، الاحتياجات/الاستثناءات، إصلاح التحويل، توضيح المبيعات، تعيين، SLA بتصعيد تلقائي، حذف الصفحتين القديمتين.
- **م2:** احتياج ← أمر شراء بزر واحد (مع صفحة المشتريات)، واجهة التحويلات (مخزن ↔ تشغيل ↔ إنتاج) مع `GET` لقايمتها، سجل أحداث الأمر، حفظ الخطة كمسودة.
- **م3:** حفظ الخطة واعتمادها بمستويات (10k/50k/200k)، حجز مخزون، دفعات وتكلفة إنتاج.
- **م4:** السعة ووعود التسليم (حمل المصانع، نطاق ثقة، سقف 85%)، وملخص يومي تلقائي للتشغيل.

## خريطة الربط بين الأقسام

مبيعات (أمر بيع مؤكد) ← **حالة تشغيل** ← تحقق ← جاهزة ← **تحويل** (وصفة لكل بند) ← أمر إنتاج `awaiting_operations_claim` ← **استلام** (بوابة المخزن/الإنتاج) ← مشرف + جودة ← مواد (مخزن) ← إنتاج ← جودة ← تسليم. عجز الخامات ← احتياج شراء ← تأكيد التشغيل ← المشتريات.

## القرارات

- `converted` حالة جديدة (عمود نص، من غير هجرة).
- ساعات العمل ثابتة في الكود (`OPS_WORK`) كقيمة افتراضية لحد ما تتحول لإعداد.
- التصعيد على cron الملخص اليومي بدل cron ثالث (حد الخطة المجانية).
