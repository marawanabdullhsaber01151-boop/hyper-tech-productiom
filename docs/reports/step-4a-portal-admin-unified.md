# Step 4a — توحيد واجهة إدارة البوابة (واجهة واحدة)

## القرار
واجهة الإدارة الجديدة (`/v2/admin/*`) بقت **الواجهة الوحيدة** لعملاء البوابة وطلبات الانضمام وطلبات التفعيل وطلبات البوابة. الصفحات القديمة اتمسحت بعد ما نقلت منها كل حاجة مفيدة. (الشات الإداري القديم والبوابة بتاعة العميل في خطوات لاحقة لأن فيهم ميزات لازم تتنقل الأول.)

## جرد الفروقات (قديم ↔ جديد) — بعد قراءة الكود
| الوظيفة القديمة | الحالة |
|---|---|
| **طلبات الأسعار (الرد بسعر مقترح/معدّل)** | **كانت ناقصة في الجديد** وخطيرة (العملاء بيبعتوها من الواجهة الجديدة) ← اتنقلت: تبويب «طلبات الأسعار» + عدّاد في صفحة طلبات البوابة |
| تعديل الحد الأدنى للطلب | كانت ناقصة ← اتنقلت لتبويب «نظرة عامة» في الشركة |
| تعديل المحافظة | كانت ناقصة ← اتنقلت (نفس المكان) |
| إيقاف/تفعيل، رابط تفعيل، كود إدارة، تصنيف، مسؤول مبيعات، تصدير CSV، الصحة | موجودة في الجديد (وأحسن: جماعي + سجل نشاط + أرشفة) |
| «حذف نهائي» للعميل | **اتشال عمدًا** — بديله الأرشفة (بتحفظ كل البيانات وتترجع) حسب قرارك |
| قايمة «طلبات إعادة تعيين كلمة السر» + تعيين كلمة سر | **ميتة**: مفيش أي كود بيسجّل طلبات في الجدول ده خلاص (الاسترجاع بقى بكود/رابط). بديلها «رابط إعادة التعيين» لكل موظف في تبويب الفريق |
| طلبات الانضمام / التفعيل (اعتماد/رفض/بحث جهات) | مغطّاة بالكامل في الجديد |
| طلبات البوابة (تأكيد/رفض/إلغاء صنف) | مغطّاة (والجديد فيه كمان «استلام للتشغيل») |

## اللي اتغيّر
- **جديد:** `web/src/admin/screens/PriceInquiries.tsx` (+ تبويب في `PortalOrders.tsx`)، وحقلي الحد الأدنى والمحافظة في `CompanyTabs.tsx`. السعر بيتحقق بنفس قاعدة السيرفر (رقم موجب بخانتين عشريتين)، وسيبه فاضي = قبول المقترح، ولو مفيش مقترح لازم يكتب سعر.
- **القايمة (`departments.ts`):** الأربع صفحات بتفتح `/v2/admin/...` مباشرة بنفس الأدوار.
- **مسح:** ٤ صفحات HTML + ٥ سكربتات + ملف CSS، وتنضيف `admin-v2-redirect.js` و`check-role-consistency.mjs` وعلم التشغيل في إعدادات البوابة (فاضل «بوابة العميل» و«الشات» بس).
- رابط «كل الطلبات» في الشركة بقى بيفتح طلبات البوابة مفلترة باسم الشركة.

## مفضّل لخطوة لاحقة
- مسارات سيرفر قديمة بقت من غير مستهلك (`/portal-orders/pending`، `/portal-customers/*` اللي مش مستخدمة، `/portal-customers/password-reset-requests`…): سبتها عشان الحذف الآمن محتاج تحليل منفصل.
- الشات الإداري: تبويبات التقارير و«من يرد؟» والردود الجاهزة (إدارة) والإعدادات والإشعارات لسه في الصفحة القديمة ← اتنفّذت في `docs/reports/step-4b-chat-admin-unified.md`.
