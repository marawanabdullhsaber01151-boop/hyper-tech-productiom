# 0048 — طيّ تبويبات الدليل الطويلة

## المشكلة
تبويبات «البيانات الأساسية» و«فهرس الشاشات والأزرار» و«كتالوجي» بقت صفحات طويلة جدًا.

## القرار
- عنصر `Fold` فوق `details/summary` الأصلية (لوحة مفاتيح وقارئ شاشة من غير كود): العنوان والوصف والعدّاد ظاهرين، والتفاصيل مطوية.
- مستويين: الكارت (مستوى 1) والخانة جواه (مستوى 2).
- `FoldTools` (افتح الكل/اقفل الكل) و`JumpBar` (شرايح قفز بتفتح العنصر وكل اللي فوقه).
- البحث في الشاشات بيفتح النتايج تلقائيًا؛ كتالوجي بيفتح الشروحات لو ≤2.
- مفيش حذف نصوص: كل مفتاح لسه بيتعرض (اختبار `guideFold.regression.test.ts`).

## بدائل اتّرفضت
أكورديون بحالة JS (أثقل وأقل إتاحة)، أو صفحات منفصلة (بتكسر القراءة المتصلة).
