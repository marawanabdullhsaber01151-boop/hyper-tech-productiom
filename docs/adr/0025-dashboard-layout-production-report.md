# ADR 0025 — تخصيص كروت اللوحة (محفوظ على السيرفر) وتقرير الإنتاج

الحالة: مقبول (الخطوة 41ب)

## القرار
1. **تفضيلات المستخدم على السيرفر** في جدول عام `user_preferences(user_id, key, value jsonb)` (هجرة 0093)، عشان الترتيب يمشي مع المستخدم على أي جهاز. أول مفتاح: `dashboard.layout` = `{ order, hidden }`.
2. المسارات `GET/PUT/DELETE /me/preferences/dashboard` كلها بـ`requireAuth` وبتشتغل على مستخدم الجلسة بس (مفيش userId في الطلب). الكتابة upsert واحد فمفيش معاملة (ADR 0008).
3. قايمة الكروت معرّفة في مكانين بيحرسهم اختبار: `src/domain/dashboardPrefs.ts` و`web/src/staff/dashboardLayout.ts`. المجهول بيتشال والناقص بيتضاف في الآخر، فكارت جديد بعد تحديث ما يختفيش.
4. الواجهة: ترتيب بالأسهم (من غير سحب، يشتغل بالكيبورد والموبايل) + إخفاء/إظهار + رجوع للأصل. الكروت اللي صلاحيات بياناتها مش متاحة للمستخدم مابتظهرش في التخصيص أصلًا. فشل الحفظ ما بيوقفش اللوحة.
5. **تقرير الإنتاج**: صف لكل أمر إنتاج اتعمل في الفترة (غير الملغي افتراضيًا). الكفاءة = المقبول ÷ المخطط، الهالك = الهالك ÷ المنتج فعليًا، كلاهما محدود بـ100 وصفر المقام = 0. الكميات بالألف والتكلفة بالقروش (BigInt). التكلفة من القيود المعتمدة بس.
6. الأدوار: الإدارة العليا + مدير الإنتاج + مدير العمليات. **أعمدة التكلفة للإدارة العليا فقط** (السيرفر مابيحسبهاش أصلًا لغيرهم).

## Rollback
`DROP TABLE IF EXISTS user_preferences;` وإرجاع ملفات الحزمة. مفيش بيانات تانية اتغيّرت.
