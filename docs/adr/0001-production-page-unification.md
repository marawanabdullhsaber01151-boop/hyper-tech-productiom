# ADR 0001: توحيد صفحات الإنتاج في صفحة واحدة

**الحالة:** مُعتمد (خطوة 22) | **القاعدة:** R4 (كل قرار كبير يتكتب قبل التنفيذ)

## المشكلة
صفحات الإنتاج القديمة (`production-requests.html` و`execution-control.html` وغيرهم) كل واحدة بتصميم وسكربت مستقل. كل صفحة بتكرر تسجيل الدخول والفحص والتنسيق، وفيها ثغرات (قايمة طلبات الإنتاج كانت مفتوحة لأي حساب مسجّل).

## الخيارات
1. إبقاء الصفحات القديمة وترقيعها. مرفوض: واجهتين لنفس الشغل، وكل إصلاح يتعمل مرتين.
2. صفحة واحدة جديدة `/v2/staff/production` بتبويبات (الطلبات، الجودة، التتبع)، وحذف القديم مع تحويل روابطه. **ده المختار.**
3. بناء صفحة لكل صفحة قديمة بشكل منفصل في v2. مرفوض: نفس التشتت بشكل جديد.

## القرار
تبويبات في صفحة واحدة، كل دور يشوف التبويبات المسموحة له بس (`availableTabs`). الصلاحيات تتفحص في السيرفر (E6)، والواجهة بس بتخفي اللي مش مسموح.

## النتائج
- فتح وقفل حالة عدم المطابقة بقى بسجل تدقيق وفي معاملة واحدة (E3, E9).
- الحالة المقفولة بتحتاج سبب جذري وإجراء تصحيحي (قاعدة `checkNcrClose`).
- الروابط القديمة بتتحوّل لتبويبها، فالإشعارات والمفضلات القديمة تفضل شغالة.
- الباقي مؤجل لخطوات جاية: `production.html` و`production-control.html` ولوحات `factory-*`.
