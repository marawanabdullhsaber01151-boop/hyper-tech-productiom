# كيفية تركيب هذا التحديث — مصفوفة الصلاحيات الكاملة + مميزات الجودة الجديدة

## ⚠️ خطوة أولى: احذف بنفسك هذين الملفين

صفحة "مراقبة الجودة" القديمة اتلغت نهائيًا (بعد نقل كل مميزاتها للصفحة الجديدة
`factory-quality-controller.html`)، وكل اللينكات ليها اتشالت من كل الصفحات.
احذف الملفين دول من مشروعك يدويًا:

```
public/qulity.html
public/JS/qulity.js
```

## 1) استبدال/إضافة الملفات (36 ملف)

كل ملف له نفس المسار بالظبط. الجديد كليًا:

```
src/lib/permissions.ts          → جديد (مصفوفة الصلاحيات الموحّدة)
public/JS/page-guard.js         → جديد (حارس الصلاحيات لكل صفحة)
```

الباقي كله استبدال لملفات موجودة (راجع محتويات الأرشيف — بنفس بنية `src/` و`public/`).

## 2) تحديث قاعدة البيانات

```bash
npm run db:push
```

(الإضافة الوحيدة الجديدة فعليًا: أعمدة الفحص بالعينة والعيوب وقائمة الفحص في
جدول `quality_records`. لو حصلت نفس مشكلة `drizzle-kit` القديمة، استخدم نفس
أسلوب سكريبت SQL اليدوي اللي استخدمناه قبل كده وقولّي أجهزلك واحد جديد).

## 3) ملخص مصفوفة الصلاحيات النهائية المطبَّقة فعليًا

| الدور                               | الصفحات                                                                                           |
| ----------------------------------- | ------------------------------------------------------------------------------------------------- |
| المدير الكامل                       | كل حاجة بلا استثناء                                                                               |
| رئيس مجلس الإدارة (`chairman`)      | مالك النشاط — صلاحية كاملة على كل الأقسام والإعدادات، وكل إجراء يُسجّل في سجل التدقيق             |
| الاتش آر (`hr`)                     | استقبال الطلبات + المبيعات + الموارد البشرية + المحاسبة + الموردين والعملاء + تعديل وصفات التصنيع |
| مدير الإنتاج (`production_manager`) | صفحته + وصفات التصنيع (عرض) + التقارير + صفحة المشرف + صفحة مراقب الجودة                          |
| مدير المخازن (`warehouse_manager`)  | صفحته + المخزون + حركات المخزون + المشتريات                                                       |
| المشرف (`supervisor`)               | صفحته بس + وصفات التصنيع (عرض)                                                                    |
| مراقب الجودة (`quality_controller`) | صفحته بس                                                                                          |

⚠️ لازم يكون عندك مستخدمين حقيقيين بكل دور من دول (من صفحة الإعدادات) عشان
تقدر تجرب كل صلاحية بشكل صحيح.

## 4) مميزات الجودة الجديدة المنقولة

صفحة `factory-quality-controller.html` بقى فيها:

- فحص بالعينة مع حساب نسبة النجاح لحظيًا وتوقّع النتيجة.
- تسجيل العيوب كـ"تاجات" منفصلة.
- قائمة فحص تفصيلية قابلة للتخصيص مع Score حي.

## 5) للتجربة

1. سجّل دخول بحساب `chairman` → افتح أي صفحة، بما فيها الإعدادات، وشوف إن
   أزرار الإضافة/التعديل/الحذف مختفية، وإنك تقدر تشوف البيانات بس.
2. جرّب نفس الحساب على المبيعات أو المشتريات — المفروض الأزرار تفضل ظاهرة
   وتقدر تتحكم بشكل كامل.
3. جرّب تفتح صفحة الإعدادات بحساب `chairman` — المفروض تفتح بنجاح، بينما
   `executive_manager` يحصل على 403.
4. جرّب حساب بدور تاني (زي `warehouse_manager`) يفتح صفحة زي المحاسبة —
   المفروض يتاخد نفس رسالة "مفيش وصول".
